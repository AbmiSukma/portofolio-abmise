Website HIMATIF: Building a Digital Hub for IT Students

Context

Campus Organization

Role

UI/UX Designer
Front-End Contributor

Focus

Visual Identity
Front-End Implementation
Web Deployment

HIMATIF needed a "digital home" to represent the face of the student association in the modern era. In this project, I took on a dual role bridging design and technology (Design-to-Code). I not only designed the visual interface of the website as an information center, but also directly contributed to writing the front-end code and managing its deployment process.

The Problem

As an informatics student association, it was highly ironic that HIMATIF did not have a professional web presence. Students found it difficult to get centralized information regarding activities, news, and association resources. On the other hand, the organization's visual identity in the digital realm was unstandardized, making it look outdated and poorly representative of the spirit of technology students.

The Approach

  • Visual Direction: Crafted a modern, energetic visual identity reflecting IT students' credibility through bold typography and color palettes.
  • UI/UX Design: Created high-resolution mockups in Figma with a mobile-first approach, ensuring information accessibility on screens of any size.
  • Front-End Engineering: Executed the designs into code (HTML/CSS/JS) paying attention to performance and micro-interactions.

The Solution

A responsive, dynamic, and youthful HIMATIF website. The homepage is designed as an interactive information hub making it easy for students to find articles, academic calendars, and work program documentation. Page transitions are designed smoothly, proving that functionality and aesthetics can go hand-in-hand.

The Results

The website was successfully deployed and runs live thanks to version control management using GitHub (fork & push) and hosting via Vercel. This project was crucial for my career development as it made me realize that mastering front-end foundations makes me a much more pragmatic designer. I now design not just by drawing pixels, but by thinking about the DOM structure, CSS styling, and the code behavior behind it.
