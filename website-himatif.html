HIMATIF membutuhkan "rumah digital" untuk merepresentasikan wajah himpunan mahasiswa di era modern. Dalam proyek ini, saya mengambil peran ganda yang menjembatani desain dan teknologi (Design-to-Code). Saya tidak hanya merancang antarmuka visual website sebagai pusat informasi, tetapi juga turun tangan langsung menulis kode front-end dan mengelola proses deployment-nya.

Masalah (Problem)

Sebagai himpunan mahasiswa informatika, sangat ironis jika HIMATIF tidak memiliki presensi web yang profesional. Mahasiswa kesulitan mendapatkan informasi terpusat mengenai kegiatan, berita, dan resources himpunan. Di sisi lain, identitas visual organisasi di ranah digital belum terstandardisasi, membuatnya terlihat usang dan kurang merepresentasikan jiwa mahasiswa teknologi.

Pendekatan (Approach)

  • Visual Direction: Meracik identitas visual yang modern, energik, dan mencerminkan kredibilitas mahasiswa IT melalui tipografi dan color palette yang berani.
  • UI/UX Design: Membuat mockup beresolusi tinggi di Figma dengan pendekatan mobile-first, memastikan aksesibilitas informasi di layar sekecil apa pun.
  • Front-End Engineering: Mengeksekusi desain tersebut ke dalam kode (HTML/CSS/JS atau framework terkait) dengan memperhatikan performa dan interaksi mikro (micro-interactions).

Solusi (Solution)

Website HIMATIF yang responsif, dinamis, dan berjiwa muda. Halaman utamanya dirancang layaknya hub informasi interaktif yang memudahkan mahasiswa menemukan artikel, kalender akademik, dan dokumentasi program kerja. Transisi antar halaman dirancang mulus, membuktikan bahwa fungsionalitas dan estetika dapat berjalan beriringan.

Hasil (Results)

Website berhasil di-deploy dan berjalan secara live berkat manajemen version control menggunakan GitHub (fork & push) dan hosting melalui Vercel. Proyek ini sangat krusial bagi perkembangan karir saya karena menyadarkan saya bahwa menguasai fondasi front-end membuat saya menjadi desainer yang jauh lebih pragmatis. Saya kini mendesain bukan sekadar menggambar piksel, melainkan memikirkan struktur DOM, styling CSS, dan behavior kode di baliknya.
